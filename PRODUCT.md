# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Mac users and developers who want one place to install and manage their apps, system packages, and developer tools. The website introduces the CLI; its documentation supports daily use.

## Product Purpose

pkg installs software through mise's bootstrap packages and tools, records installations in the global mise configuration, and lets mise bootstrap restore that configuration on another machine.

## Positioning

The Mac's missing package manager: the ultimate system package manager for Mac apps, command-line packages, and developer tools. The user explicitly chose this Mac-first marketing position. pkg remains a human-first command-line front end for mise; JSON output and built-in discovery also serve agents and scripts. The marketing emphasis does not remove support for other platforms from the current CLI contract.

The user also wants the copy to emphasize that pkg just works out of the box and its commands do what people expect. Support this with its shared command vocabulary and defaults; keep the required mise installation and current source-build steps explicit in the docs.

## Capabilities and Constraints

Current behavior is owned by README.md and crates/pkg/docs/cli.md. Unimplemented proposals are not product capabilities. No published release exists at the time this site is created; installation instructions must provide the working source-build route rather than promise an installer or published package.

The website uses the local content-website template's Astro, React/Redact, Tailwind and Cloudflare stack. Starlight provides documentation under /docs. Deployment and the production domain are not yet chosen.

## Brand Commitments

Use the supplied pkg vector logos in assets. The supplied identity reference establishes bold rounded italic lettering, charcoal, yellow, and an off-white supporting surface. The user grants creative freedom for the site and permits use of the middle-school “Got pkg?” poster.

## Evidence on Hand

The CLI README and generated command reference describe supported commands. assets/pkg-logo-light-mode.svg and assets/pkg-logo-dark-mode.svg are supplied identity assets. The source campaign image is got-pkg.png in the user's supplied logo folder. There are no supplied testimonials, adoption figures, performance benchmarks, or customer claims.

The supplied moving-box artwork appears as a decorative image beside the final installation action, optimized at `site/app/assets/moving-box.webp`.
